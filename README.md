# Análisis de Datos de Vehículos Usados 🚗📊

Este proyecto consiste en una aplicación interactiva desarrollada con **Streamlit** para realizar un análisis exploratorio de datos sobre vehículos usados en Estados Unidos.

El objetivo es comprender la estructura del dataset, identificar valores faltantes y analizar la distribución de precios como base para la toma de decisiones comerciales.

## 🛠️ Tecnologías utilizadas
- Python
- Pandas
- Matplotlib
- Streamlit

## 🔍 Análisis realizado
- Visualización de las primeras filas del dataset
- Revisión de la información general
- Identificación de valores faltantes
- Estadísticas descriptivas
- Histograma de la distribución de precios

pip install -r requirements.txt

## 📌 Conclusiones
- El dataset contiene valores faltantes que deben tratarse antes de análisis más avanzados
- La distribución de precios presenta una asimetría positiva
- El análisis exploratorio permite detectar oportunidades para segmentación de mercado
